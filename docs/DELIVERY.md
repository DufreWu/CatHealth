## 验证结果

- Python unittest：29 项通过（原爬虫 15 项，营养/数据库/API 14 项）。
- JavaScript：`node --check web/app.js` 通过。
- Chromium 实际浏览器：页面通过 fetch 请求真实 HTTP API，SQLite 临时库由启动脚本初始化。通过商品列表、2 商品对比、详情、湿粮碳水隐藏、处方粮默认隐藏/手动显示、空搜索、方法页、复核页测试。
- 响应式：1440px 桌面和 390px 手机宽度；手机没有页面横向溢出。
- 浏览器未捕获 JavaScript 异常。
- 真实数据：使用原包历史 JSON/HTML 快照离线迁移验证；未对当前零售网站执行新采集，因此不声称通过全站或当前动态 DOM 验收。
